01 / THE PROJECT

What is EIRLYS?

PROJECT OVERVIEW

An interactive AI
VTuber system.

EIRLYS คือระบบ AI VTuber ที่พัฒนาขึ้นเพื่อให้ตัวละครเสมือนสามารถพูดคุยและโต้ตอบกับผู้ชมระหว่างการถ่ายทอดสดบน YouTube ได้โดยอัตโนมัติ

ระบบทำงานโดยรับข้อความจากผู้ชม ประมวลผลและสร้างคำตอบด้วยโมเดลภาษา AI (LLM) ที่ทำงานภายในเครื่อง จากนั้นแปลงคำตอบเป็นเสียงพูด พร้อมควบคุมการขยับปาก สีหน้า และท่าทางของตัวละครให้สอดคล้องกับบทสนทนา

นอกจากนี้ EIRLYS ยังมีระบบจัดการคิวข้อความ ระบบความจำที่คำนึงถึงความยินยอมของผู้ชม และ EIRLYS Studio สำหรับควบคุมและตรวจสอบการทำงาน โดยมีเป้าหมายเพื่อสร้าง AI VTuber ที่สามารถสื่อสารกับผู้ชมได้อย่างเป็นธรรมชาติ และแสดงให้เห็นการทำงานร่วมกันของเทคโนโลยี AI เสียงสังเคราะห์ และแอนิเมชันสามมิติ

04 / FUNCTION INDEX

Core capabilities.

01 / AI

Local LLM Conversation

สร้างคำตอบด้วย Qwen ผ่าน LM Studio โดยใช้โมเดลที่ทำงานในเครื่อง

02 / FLOW

Smart Queue & Rhythm

จัดข้อความและเว้นจังหวะเพื่อไม่ให้ AI พูดซ้อนหรือพูดถี่เกินไป

03 / AUDIO

Voice Synthesis

สร้างเสียงผ่าน ElevenLabs แล้วส่งสัญญาณเสียงไปยังระบบ Avatar

04 / MOTION

Expression & Lip Sync

การเคลื่อนไหวปาก สีหน้า ศีรษะ ลำตัว และการแสดงอารมณ์ผ่าน VNyan

05 / EYES

Eye Gaze & Blink

ควบคุมการมองและการกะพริบตาให้ดูเป็นธรรมชาติขึ้น

06 / MEMORY

Audience Memory

ดูแลบริบทสนทนาและการบันทึกความจำโดยคำนึงถึงการยินยอม

07 / OWNER

Direct Speak / Song Stage

รองรับการสั่งพูดตรงด้วย /say และระบบเพลงที่เพิ่มเข้ามาใน 4.0.5

08 / OPS

Studio Control Center

แยกหน้าควบคุม การสั่งงาน และการตรวจสอบสถานะ/Logs ให้ชัดเจน
